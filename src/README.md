Como solução para os problemas enfrentados,
a PetVida contará com um Sistema de Gerenciamento de Banco de Dados (SGBD) relacional para centralizar e organizar as
informações da clínica. O banco permitirá armazenar os dados dos tutores, animais, veterinários, consultas, procedimentos e demais informações necessárias, mantendo os registros relacionados entre si.

Com os dados centralizados,
será possível localizar o histórico dos animais com mais facilidade, 
acompanhar consultas e 
procedimentos realizados, reduzir informações duplicadas ou desatualizadas e facilitar o acesso aos dados dos tutores e veterinários. Dessa forma, o SGBD contribuirá para tornar o atendimento mais organizado, seguro e eficiente.
